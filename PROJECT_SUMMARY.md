## Repository Description

### Short Description (for GitHub):

```
PowerShell toolkit for converting PubMed/MEDLINE citations to RIS format with data extraction to CSV/Excel. Perfect for systematic reviews, literature searches, and citation management. Simple, fast, no dependencies.
```

### Alternative Descriptions:

**Option 1 (Technical)**:
```
PowerShell scripts for NBIB-to-RIS conversion, PubMed URL enrichment, and citation data extraction. Supports batch processing, web scraping, and CSV export for systematic reviews and literature analysis.
```

**Option 2 (User-Friendly)**:
```
Convert PubMed citations to RIS format and extract to Excel with ease. Automate your literature search workflow with these simple PowerShell tools. No installation required, just run and go.
```

**Option 3 (Research-Focused)**:
```
Streamline your systematic review workflow. Convert MEDLINE/NBIB files to RIS, enrich with PubMed URLs, and export to CSV for analysis. Built for researchers, by researchers.
```
